📖 香港保险中介人资格考试（IIQE）

Insurance Intermediaries Qualifying Examination · 一文看懂考试内容、各卷科目、报名方式与高效备考。

01 · IIQE 是什么？

香港保险中介人资格考试（IIQE）是香港保险业的中介人资格考核，由职业训练局（VTC）辖下的高峰进修学院（PEAK）举办，考试成绩获保险业监管局（IA）认可，是成为持牌保险代理人 / 保险经纪的重要条件。

简单来说：想在香港合法从事保险销售或中介业务，就要先通过相应试卷、取得牌照。

02 · 考试科目总览

IIQE 按业务线分为多个试卷，从业者须按其业务范围通过相应试卷：

试卷名称适用对象
卷一保险原理及实务所有保险中介（必修）
卷二一般保险一般（财产）保险中介
卷三长期保险长期（人寿）保险中介
卷五投资相连长期保险投连险中介

本 App 目前覆盖 卷一 与 卷三 两卷，题库共 0 题（卷一 0 + 卷三 0，含原创 0 题与真实题 0 题）。另有旅游保险等专项考试，具体以官方公布为准。

03 · 卷一《保险原理及实务》

75题目数
120分钟
70%及格线

及格线 70%，相当于约答对 53 题。

全卷共 7 章：风险与保险、保险之法律原则、保险原则（可保利益 / 最高诚信 / 近因 / 赔偿）、保险公司之运作与功能、保险业之结构、香港保险业之规管架构、职业道德与操守。

卷一是所有保险中介的必修卷，无论从事人寿还是财产保险，都要先过这一关。

04 · 卷三《长期保险》

50题目数
75分钟
70%及格线

及格线 70%，相当于约答对 35 题。

全卷共 5 章：人寿保险简介、寿险及年金种类、附约产品、保单条款阐释、寿险程序。

卷三适合计划从事人寿 / 长期保险（如储蓄、危疾、年金等产品线）的从业者。

05 · 考试形式

  • 全卷为多项选择题（四选一）。
  • 中英对照：题目与选项同时提供中文及英文。
  • 采用电脑化考试（CBT），在指定考场进行。
  • 全卷一个总分，70% 或以上即及格，不设分题及格线。

06 · 报名流程与官方入口

📖IIQE 考试专页高峰进修学院 PEAK · 考试详情 🖥️网上报名系统PEAK 考试中心 · 报名入口 📝报名程序报名手续与所需文件 💳缴费方法考试费用与付款方式 🏛️保险业监管局（IA）发牌要求与中介人规管
  1. 前往 PEAK 考试专页 了解最新考试日程、考卷与费用。
  2. 通过 网上报名系统 注册 / 登录，选择报考试卷（如卷一、卷三）及考试场次。
  3. 按 缴费方法 缴纳考试费用并确认报名。
  4. 按指定时间、地点到考场应试（带备有效身份证明文件）。
  5. 考试后于报名系统查询成绩；发牌及中介人规管资讯以 保监局（IA） 为准。

📞 报名 / 考试查询热线：2919 1467 · 2919 1468 · 2919 1478（PEAK 考试中心）。考试费用、场次与地点会随官方安排调整，请以 PEAK 及保监局最新公布为准。

07 · 备考攻略：如何高效通过？

第一步 · 建立知识框架

通读官方考试范围 / 教材，重点掌握保险原则（可保利益、最高诚信、近因、赔偿）与契约法基础，这是卷一的重头戏。

第二步 · 分章节刷题

用本 App 的「章节专项练习」逐章突破，每章做完后针对错题反复巩固，形成长期记忆。

第三步 · 智能 & 随机检验

用「智能刷题」聚焦薄弱点、用「随机 20 题」打乱顺序避免死记；临考前用「模拟考试」计时检验。

第四步 · 死磕错题本

答错的题会自动进入「错题本」，考前把错题清零，往往是提分最快的环节。

⏱️ 时间管理参考：卷一 120 分钟 75 题 ≈ 每题 1.6 分钟；卷三 75 分钟 50 题 ≈ 每题 1.5 分钟。

08 · 常见问题（FAQ）

考试用中文还是英文？

题目及选项均为中英对照，可按个人习惯作答。

可以一次报考多份试卷吗？

各试卷独立报考，可依发牌要求与个人安排分次或依次报考。

考试不通过可以重考吗？

可以，重新报名参加下一次考试即可，重考规则以官方为准。

成绩何时公布？

电脑化考试通常于考试后一段时间内在报名系统公布，具体以 PEAK 通知为准。
